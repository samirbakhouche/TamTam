🚀 دليل نشر واستضافة خادم طمطم مجاناً 100%

خطوات تشغيل الـ REST API وسيرفر الـ WebSockets وقاعدة بيانات MySQL مجاناً بالكامل

1. استضافة الخادم على Render.com
مجاني Free Tier

يدعم تشغيل كود Node.js مع بروتوكول WebSockets وشهادة حماية SSL/HTTPS مجانية مدى الحياة.

• المستودع: ارفع مجلد backend إلى GitHub
• Build Command: npm install
• Start Command: node src/server.js
2. استضافة MySQL مجانية (Aiven / TiDB)
قاعدة بيانات سحابية

تمنحك منصة Aiven.io أو TiDB Cloud قاعدة بيانات MySQL سريعة مع 5GB مجاناً.

• الصق كود الترحيل من: backend/database/migrations/core_schema.sql
• انسخ رابط الاتصال في ملف .env
📲 ربط تطبيق الأندرويد بالخادم السحابي الجديد:

بعد رفع الخادم والحصول على عنوان الرابط الخاص بك (مثلاً: https://tamtam-api.onrender.com):
1. افتح تطبيق طمطم على هاتفك ⭢ الإعدادات (Settings).
2. في خانة عنوان الخادم (Backend URL)، ضع رابط الخادم الجديد واضغط حفظ واختبار الاتصال.
3. سيتصل هاتفك فوراً بالسيرفر وقاعدة البيانات السحابية الحقيقية!

📖 شرح المعمارية والهندسة البرمجية لتطبيق طمطم

1. تطبيق الأندرويد (Android Client)

مبني وفق معمارية Clean Architecture + MVVM، باستخدام Jetpack Compose بالكامل، مع دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL). يعتمد قاعدة بيانات Room لتخزين المحادثات والرسائل محلياً ليعمل التطبيق بسرعة فائقة ودون انقطاع (Offline-First).

2. الخادم ومحرك التراسل اللحظي (Backend & WebSockets)

خادم مبني بلغة Node.js/Express، يحتوي على بوابات REST API للمصادقة وتحديث الحسابات، ومزود بمحرك WebSockets للتواصل المباشر وتسليم الرسائل ومؤشرات الكتابة وحالة الاتصال فورياً بـ 0 تأخير.

3. قاعدة البيانات العلائقية (MySQL Schema)

تضم 19 جدولاً مترابطاً مع مفاتيح أجنبية وفهارس مركبة وفهرسة نصية كاملة (Fulltext Search) على محتوى الرسائل للبحث السريع، مع مشغلات (Triggers) لتحديث آخر رسالة تلقائياً.
